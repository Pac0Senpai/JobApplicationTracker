# Job Application Tracker

A console-based Java application for tracking job applications, built as my first portfolio project.

The application allows users to add, view, update, and search job applications while storing all data persistently in a MySQL database through JDBC.

## Features

- Add a new job application
- View all saved applications
- Update the status of an application by ID
- Search applications by company
- Persistent storage using MySQL
- Secure database access using a dedicated MySQL user
- Database password stored outside the source code using an environment variable
- SQL queries executed with `PreparedStatement`
- Database results processed using `ResultSet`

## Database

The application uses a MySQL database named:

```sql
job_application_tracker
```

The main table is:

```sql
job_applications
```

### Table Structure

```sql
CREATE TABLE job_applications (
    id INT AUTO_INCREMENT PRIMARY KEY,
    company VARCHAR(100) NOT NULL,
    position VARCHAR(100) NOT NULL,
    application_date DATE NOT NULL,
    status VARCHAR(100) NOT NULL,
    notes VARCHAR(255)
);
```

Each application contains:

| Field | Description |
|---|---|
| `id` | Unique application ID generated by MySQL |
| `company` | Company name |
| `position` | Job position |
| `application_date` | Date the application was submitted |
| `status` | Current application status |
| `notes` | Optional notes |

## JDBC Integration

The application connects to MySQL using JDBC.

Database connections are handled by the `DatabaseConnection` class.

Example JDBC URL:

```text
jdbc:mysql://localhost:3306/job_application_tracker
```

The application uses a dedicated MySQL user instead of connecting as `root`.

## Environment Variable

The database password is not stored directly in the Java source code.

Instead, it is loaded from the following environment variable:

```text
JOBTRACKER_DB_PASSWORD
```

Java retrieves it using:

```java
public class DatabaseConnection {
    private static final String PASSWORD =
            System.getenv("JOBTRACKER_DB_PASSWORD");
}
```

This prevents database credentials from being committed to GitHub.

## MySQL User Setup

A dedicated database user can be created with:

```sql
CREATE USER 'jobtracker_user'@'localhost'
IDENTIFIED BY 'your_password';
```

The required permissions can then be granted:

```sql
GRANT SELECT, INSERT, UPDATE, DELETE
ON job_application_tracker.*
TO 'jobtracker_user'@'localhost';
```

## Running the Project

### Requirements

Make sure the following are installed:

- Java 21
- Maven
- MySQL Server

### Setup

1. Clone the repository.

2. Create the MySQL database:

```sql
CREATE DATABASE job_application_tracker;
```

3. Create the `job_applications` table using the schema above.

4. Create the `jobtracker_user` MySQL account.

5. Create the environment variable:

```text
JOBTRACKER_DB_PASSWORD
```

6. Make sure MySQL is running.

7. Open the project in IntelliJ IDEA.

8. Reload the Maven project so that the MySQL JDBC driver is downloaded.

9. Run:

```text
Main.java
```

## Example Workflow

A user can add a new job application:

```text
Company: Deloitte
Position: Junior SAP ABAP
Notes: Application submitted
```

The application stores it directly in MySQL.

It can later be viewed:

```text
1 | Deloitte | Junior SAP ABAP | 2026-10-19 | Applied | Application submitted
```

The status can then be updated:

```text
Enter application ID: 1
Current status: Applied
Do you want to update the status? (y/n): y
Enter new status: Interview

Status updated successfully.
```

The updated value is persisted in the database.
